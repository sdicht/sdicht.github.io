ANSWER KEY (For Teacher Use)

Section 1: Mistake Hunting

Text A: 1. exciting → excited 2. If I will study → If I study 3. reviewing → review 4. said me → told me 5. are → is

Text B: 1. will help → would help 2. was → were 3. wouldn't had → wouldn't have 4. were → was 5. told to the class don't → told the class not to

Text C: 1. carefully → careful 2. who lives → that live 3. mustn't to go → mustn't go 4. should bringing → should bring 5. If you will see → If you see (Note: "worry" → "worried" was in original answer but not in text)

Text D: 1. are → is 2. which → who 3. didn't had → didn't have 4. shouldn't never → should never 5. Neither wisdom or → Neither wisdom nor

Text E: 1. challenged → challenging 2. must to practice → must practice 3. careful → carefully 4. don't will → don't 5. told to everyone → told everyone to

Text F: 1. If I will catch → If I catch 2. safely → safe 3. frightening → frightened 4. said to Robin don't → told Robin not to 5. No error (or "had escaped" → "has escaped" depending on context)

Text G: 1. confusing → confused 2. didn't been → hadn't been 3. has showing → has shown 4. said me → told me 5. No additional error or "who I thought" → "whom I thought"
